# Himawari docs 

Himawari is a visual novel engine. You write your story, play it as you write, and share it as a small Windows game that starts with a double-click.

- **No code needed.** Everything can be done in Himawari Studio with buttons, forms, and pickers.
- **Coders welcome.** The same project is plain text files, a command line, and git.
- **Light on any Windows PC.** Games are tiny native programs for Windows 10 and 11.
- **AI is optional.** It's a helper you can ignore completely.
