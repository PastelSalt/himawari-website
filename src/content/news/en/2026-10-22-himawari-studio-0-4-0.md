The first public build of Himawari Studio, the editor for making visual novels with Himawari.

Studio, the engine, and game export work from start to finish and are covered by automated tests, but testing with real writers hasn't started yet, so expect rough edges and please report them.

Everything is inside the installer: the game engine, the command-line tools, the tutorial, and three sample games.
