Himawari は、Windows で使える無料・オープンソースのビジュアルノベルエンジンとエディタです。[Moeko Works](https://moekoworks.vercel.app/)（GitHub では [PastelSalt](https://github.com/PastelSalt)）が作っています。

大切にしているのは 3 つの約束です。**だれでも使えること、コードを書く人にもひらかれていること、どの Windows PC でも軽く動くこと。** Studio ではコードを書かずにすべての作業ができ、同じプロジェクトは、コードを書く人にとってはプレーンテキストのファイルです。完成したゲームは Windows 10・11 ならダブルクリックで起動し、何もインストールする必要がありません。AI 機能は任意で、Himawari が画像、音楽、音声、動画を生成することはありません。

いまのバージョンは、最初期の公開版です。最初から最後まで使えますが、実際の書き手によるテストはまだこれからです。できていること、これからのこと、いまの制限は [README](https://github.com/PastelSalt/himawari-c#readme)（英語）にまとめています。

## プロジェクトの運営

バージョン 1 までは、何を Himawari に入れ、いつ公開するかを Moeko Works が決めます。どの判断も 3 つの約束に照らして行い、理由は決定記録と RFC に公開で書き残しています。

- **不具合の修正、ドキュメント、テスト、小さな改善**は、プルリクエストでメンテナーがレビューします。
- **スクリプト言語、バイトコード、ファイル形式の変更**には、先に RFC が必要です。ゲーム、ツール、AI アシスタントのすべてがそれに頼っているからです。

意思決定の方法は [GOVERNANCE.md](https://github.com/PastelSalt/himawari-c/blob/main/GOVERNANCE.md)、参加の方法は [CONTRIBUTING.md](https://github.com/PastelSalt/himawari-c/blob/main/CONTRIBUTING.md)（どちらも英語）にあります。

## ライセンス

| 部分                                     | ライセンス                                       |
| ---------------------------------------- | ------------------------------------------------ |
| すべてのゲームに含まれるゲームランタイム | zlib                                             |
| ツール、コンパイラ、MCP サーバー、Studio | MIT                                              |
| 仕様と RFC                               | CC BY 4.0                                        |
| テンプレートとサンプルゲーム             | CC0 1.0                                          |
| Himawari と Moeko Works の名前とロゴ     | オープンではありません。Moeko Works に帰属します |

Himawari で作ったゲームは販売できます。zlib ライセンスでは Himawari のクレジット表記は必須ではありませんが、書いていただけるとうれしいです。

## 名前とロゴ

Himawari と Moeko Works の名前とロゴは Moeko Works に帰属し、オープンライセンスの対象ではありません。フォークではコードを使い続けられますが、名前とロゴは独自のものにしてください。Himawari で作ったゲームには、これらのロゴは含まれません。
